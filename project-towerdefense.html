Wakes

About the project

How it works

↗ App Store

In Wakes, enemies follow a path toward the village. Throw bombs with your hands to stop each wave—and get ready for the next.

Defeated enemies earn you money for upgrades between waves. The game uses hand tracking for input and RealityKit for the immersive world.

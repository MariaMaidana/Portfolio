Wakes

Wakes is a tower defense game for Apple Vision Pro where you protect the base by throwing darts with your hands.

About the project

How it works

Enemies follow a path toward the village. You stop them by aiming and throwing darts with hand gestures. Each wave brings a new challenge.

Defeated enemies earn you money for upgrades between waves. The game uses hand tracking for input and RealityKit for the immersive world.
